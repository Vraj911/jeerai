⚡ Spring Application Event Bus (Automation Engine)
IssueService publishes AutomationEvent → AutomationExecutionService listens
@TransactionalEventListener(AFTER_COMMIT) — fires only on committed data
issue_created→all enabled rules evaluated for project
status_change→match trigger type + optional value
priority_change→evaluate conditions on fresh Issue
assignee_change→execute action if all conditions pass
🛡 ThreadLocal depth guard (max 3) prevents infinite chains
EventOrigin.USER vs AUTOMATION prevents re-triggering on automation actions
🔄 Key Workflows — Class Call Chains
🔐 Signup / Login
  • AuthController.signup()
  • AuthService validates email uniqueness
  • UserService.createUser()
  • BCryptPasswordEncoder.encode()
  • UserRepository.save()
  • JwtUtil.generateToken()
  • → AuthResponse { token, UserDto }
📧 Workspace Invite
  • InvitationController.createInvitation()
  • WorkspaceMemberService.checkAdminAccess()
  • InvitationService validates, generates SecureRandom token
  • InvitationRepository.save()
  • InvitationDeliveryService.send()
  • → SmtpDeliveryService (mail.enabled=true)
  • → NoOpDeliveryService (default, logs only)
📁 Project Creation
  • ProjectController.create()
  • WorkspaceAccessService.requireWorkspaceAdminAccess()
  • ProjectService deduplicates key in workspace
  • ProjectRepository.save()
  • ProjectPermissionService.updatePermissions()
  • → Seeds default permission matrix for all roles
🎫 Issue Creation
  • IssueController.create()
  • WorkspaceAccessService.canCurrentUser(CREATE_ISSUES)
  • IssueService.create() → saves issue
  • ActivityRepository.save() "issue_created"
  • NotificationRepository.save() notify assignee
  • Publishes AutomationEvent(issue_created)
  • AutomationExecutionService fires AFTER_COMMIT
🔄 Issue Status Update
  • IssueController.updateStatus()
  • WorkspaceAccessService.canCurrentUser(EDIT_ISSUES)
  • IssueService captures before-snapshot
  • Updates status, sets updatedAt=now
  • Publishes status_change AutomationEvent
  • ActivityRepository.save()
  • Notifies assignee + reporter (skip self)
🤖 AI Request
  • AiController.sendMessage()
  • AiService checks access + API key validity
  • AiContextService.loadContext(mode, projectId)
  • AiPromptBuilder loads .txt system prompt from classpath
  • BeanOutputConverter appends JSON schema to prompt
  • ChatClient.prompt().call() → OpenRouter
  • AiResponseMapper.map() → AiMessageResponse
⚙️ Automation Fires
  • AutomationExecutionService.onAutomationEvent()
  • Guard: EventOrigin == USER only
  • Guard: ThreadLocal depth < maxDepth(3)
  • AutomationConditionEvaluator.evaluate()
  • status_is · priority_is · assignee_is · label_contains
  • AutomationActionExecutor.execute()
  • change_status | assign_user | add_label | send_notification
📈 Analytics
  • AnalyticsController.getProjectAnalytics()
  • WorkspaceAccessService.canCurrentUser(VIEW_ANALYTICS)
  • IssueRepository.findByProjectId() all issues
  • In-memory groupBy status, priority, assignee
  • SprintRepository.findByProjectId() for velocity
  • → statusCounts, completionData, velocityData, workload
🚀 Onboarding
  • WorkspaceController.getOnboardingStatus()
  • WorkspaceService.getOnboardingStatus()
  • WorkspaceMemberService.getMembershipsForCurrentUser()
  • → { isNewUser, workspaceCount, workspaceList }
  • Frontend shows setup wizard if isNewUser=true
🔔 Notifications (Paged)
  • NotificationController.getPage(page, size)
  • NotificationService clamps size to MAX 100
  • NotificationRepository.findByRecipientUserId(Pageable)
  • → Page<AppNotification> with metadata
  • markRead(id) · markAllRead() updates is_read
🤖 AI Context Modes — Data Sent to LLM
✨ GENERATE
  • GenerateContext record
  • projectName, key, desc
  • Open issues (≤50)
  • Sorted by priority
  • → GenerateIssuesOutput
  • Returns IssueDraftOutput[]
📋 SUMMARY
  • SummaryContext record
  • countByStatus Map
  • countByPriority Map
  • unassignedOpen count
  • recentActivity (7 days)
  • → BacklogSummaryOutput
🎯 PRIORITIES
  • PriorityContext record
  • Open issues (≤30)
  • Sorted updatedAt DESC
  • assigneeName, labels
  • → PriorityListOutput
  • Ranked suggestions[]

uuid id PK · public_id UNIQUE · name · project_id FK · start_date · end_date · is_active
issues
uuid id PK · public_id UNIQUE · key UNIQUE · title · status · priority · assignee_id FK→users · reporter_id FK→users · project_id FK · sprint_id FK (nullable) · description · created_at · updated_at

issue_comments
uuid id PK · public_id UNIQUE · issue_id FK · author_id FK→users · content(text) · created_at
